Archipelago Atlas is a static national statistics site for Indonesia: population, economy, work, prices, regions, provinces, and source notes in one offline-friendly page set.

## Run it

```sh
node serve.ts
```

Then open the local address printed by the server. To build the make.fun hand-in output locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
